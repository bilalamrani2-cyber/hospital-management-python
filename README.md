# Hospital Management Python Project

This project is a beginner Python application for managing hospital data.

## Project Overview
The system is designed to manage:
- Patients
- Doctors
- Hospital services

It uses basic Python data structures and functions to simulate a simple hospital management workflow.

## Features
- Add a new patient
- Display all patients
- Filter patients by status
- Assign a patient to a doctor
- Count patients assigned to each doctor
- Check available hospital services
- Sort and process patient data

## Python Concepts Used
- Lists
- Dictionaries
- Tuples
- Functions
- Loops
- Conditions
- Filtering
- Mapping
- Lambda expressions

## Example Tasks
- Add and remove patients
- Update a patient’s condition
- Assign a patient to a doctor
- Display critical patients
- Extract patient names
- Sort patients by age
- Simulate a simple menu-based system

## Tools
- Python

## Purpose
This project was created to practice Python programming, data structures, and basic problem-solving for entry-level technical and data-related roles.
